Unterstützte Plattformen

Zwei Zielplattformen, ein Workflow

🎵 TikTok

TikTok Content Posting API

Clips werden via offizieller TikTok Content Posting API hochgeladen — entweder als Draft in den TikTok‑Posteingang oder als Direct Post. OAuth 2.0, Scope video.upload + video.publish.

TikTok Privacy · TikTok Developer Terms

▶️ YouTube Shorts

YouTube Data API v3

Dieselben vertikalen Clips werden parallel auf den eigenen YouTube‑Kanal als Short gemirrort — via videos.insert (resumable upload). OAuth 2.0, Scopes youtube.upload + youtube.readonly. Zugriff ausschließlich auf den eigenen autorisierten Kanal des Betreibers.

YouTube Terms · YouTube API Developer Policies · Google Privacy Policy
